Atividade 2 — Desenvolvendo com Box Model

Diagrama do Box Model

Todo elemento HTML é composto por quatro camadas: Margin (espaço externo) → Border (borda) → Padding (espaço interno) → Content (conteúdo).

Margin (30px)
Border (2px solid)
Padding (20px)
Content
200px × 100px

Exemplo 1 — box-sizing: content-box (padrão)

Comportamento padrão do CSS. O width: 200px define apenas o conteúdo. A largura total ocupada na página é: 200 (content) + 40 (padding) + 4 (border) + 60 (margin) = 304px.

Conteúdo (200×100)

Exemplo 2 — box-sizing: border-box

Com box-sizing: border-box, o width: 200px passa a incluir o padding e a border. A largura total fica fixa em 200 (tudo incluso) + 60 (margin) = 260px. Muito usado em projetos modernos para facilitar o cálculo de layouts.

Border-box (200px total)
