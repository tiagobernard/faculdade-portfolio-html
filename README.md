### Visão Geral
Este repositório apresenta duas atividades desenvolvidas no módulo de **Programação com Linguagem de Marcação** da disciplina **Fundamentos em HTML** e **Técnicas e Aplicações de HTML e CSS** do curso superior de tecnologia **Sistemas para Internet** (quinto período). As atividades demonstram a criação de formulários modernos em HTML5 e a aplicação prática do **Box Model** com CSS.

### Roteiro de Aula Prática
#### Unidade 1 – Fundamentos em HTML – Seção: Construindo formulários
**Objetivos**
- Compreender o conceito de formulários em HTML.
- Criar formulários usando HTML e HTML5.
- Manipular atributos da tag `<form>` (action, method).
- Utilizar elementos `<input>` para coleta de dados.
- Aplicar estilos CSS básicos.

**Procedimentos**
1. **Introdução** – importância dos formulários e diferenças entre HTML e HTML5.
2. **Formulário simples** – `<form action="processar_formulario.php" method="post"></form>`
3. **Elementos de formulário** – adicionar `<label>` e `<input type="text">`, `<input type="submit">`, `<input type="reset">`.
4. **Estilização (opcional)** – aplicar CSS para layout responsivo.
5. **HTML5 – novos tipos** – `<input type="email">`, `<input type="tel">`, `<input type="date">`.

**Checklist**
- Formulário com `action` e `method` definidos.
- Campos `<input>` incluídos e com atributo `name`.
- Estilos CSS aplicados (opcional).
- Utilização de tipos HTML5.

**Resultado de Aprendizagem** – o aluno é capaz de criar formulários completos em HTML5 e compreender os atributos da tag `<form>`.

#### Unidade 3 – Técnicas e Aplicações de HTML e CSS – Seção: Desenvolvendo com Box Model
**Objetivos**
- Entender o Box Model e sua influência no layout.
- Criar estrutura HTML básica e vincular folha de estilos CSS.
- Definir dimensões, padding, border e margin em CSS.
- Visualizar o resultado no editor online.

**Procedimentos**
1. Acessar o **W3Schools Tryit Editor**.
2. Criar documento HTML básico com referência a `style.css`.
3. No CSS, definir a classe `.box` com `width:200px; height:100px; padding:20px; border:2px solid #333; margin:30px;`.
4. Executar e observar a renderização.

**Checklist**
- Estrutura HTML criada.
- Arquivo CSS criado e linkado.
- Estilos de Box Model aplicados.
- Projeto visualizado no editor.

**Resultado de Aprendizagem** – o aluno compreende o Box Model e consegue construir layouts usando CSS.

### Tecnologias Utilizadas
- **HTML5** – marcação semântica e novos tipos de campos.
- **CSS3** – flexbox, sombras, box‑model e responsividade.
- **W3Schools Tryit Editor** – ambiente de teste online.
